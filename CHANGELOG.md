# Changelog

All important changes to this project are documented in this file.

This project follows Semantic Versioning (SemVer).

## [1.0.0] - 2026-11-17

### Breaking Changes
- Introduced a Git-based development workflow.
- Replaced the manual code validation process with automated CI checks.
- Developers must follow the Pull Request workflow before merging code.

### New Features
- Integrated GitHub Actions for CI/CD automation.
- Added Flake8 for Python code quality checking.
- Added Pytest for automated unit testing.
- Configured automatic workflow execution on code pushes and Pull Requests.
- Added build status reporting.
- Introduced professional project documentation.

### Bug Fixes
- Fixed Python coding standard violations.
- Corrected issues identified through automated testing.
- Improved consistency in dependency installation.
- Reduced the risk of errors through automated validation.

### Release Summary
Version 1.0.0 introduces an automated CI/CD workflow that improves code quality, testing, collaboration, and software development reliability.
